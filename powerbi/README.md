# Power BI report

Open `project/RetentionAnalysis.pbip` in Power BI Desktop.

The committed project uses a placeholder `DataFolder` path so it does not expose a personal computer path. After cloning or downloading the repository, set `DataFolder` to the full local path of this project's `data/powerbi` folder and select **Refresh**.

The report contains three pages:

1. **Retention overview** — repeat revenue and cohort retention;
2. **Segment decision** — historical segment backtest and current portfolio;
3. **CRM priorities** — target markets, customers, and familiar products.

All report labels are in English. The screenshots folder contains clean static versions for GitHub.
